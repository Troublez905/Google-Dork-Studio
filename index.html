// FAQ

Clear answers before you begin

Does the app run searches automatically?

No. It only generates and displays local query templates.

Does it collect analytics or assessment data?

No. The default build has no analytics, account system, telemetry service, or remote database.

Can I add custom templates?

Yes. Categories, descriptions, and query templates are stored in an editable JSON file.

Is internet access required?

No. Generation and clipboard features work locally.

What does authorized use mean?

Use the software only with systems you own or have explicit permission to assess.
