Contributing to Dorks VA

Thanks for contributing! To get started:

- Fork the repo and open a pull request with a clear description.
- Run locally:
  - Install dependencies: npm ci
  - Start local Netlify dev: npm run dev (requires Netlify CLI)
  - Run typecheck: npm run typecheck
- Keep sensitive keys out of commits; use .env.example as reference.
- For code changes, prefer small, focused PRs with tests or verification steps.

Reporting issues: use the provided issue templates. For feature requests, explain the user benefit and a suggested UI flow.
